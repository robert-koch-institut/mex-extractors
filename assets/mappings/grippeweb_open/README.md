# GrippeWeb Mapping

## access-platform.yaml
Access platform-item is the SQL-server.

## resource_grippeweb.yaml
This file does not contain rules for extraction and transformation, but values. The file corresponds with a resource-item.

Variable groups and variables will only be connected to this item.

## resource_grippeweb-plus.yaml
This file does not contain rules for extraction and transformation, but values. The file corresponds with a resource-item.

This item has neither variable groups nor variables.

## variable-group.yaml
For each table in SQL server there is one corresponding variable group.

## variable.yaml
A variable corresponds to a column in a SQL-table.
